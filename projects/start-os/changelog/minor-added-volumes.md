- Share data between services, or with other devices, using local folders, folders on external drives and CIFS shares in System → Shared Volumes, with separate No Access, Read and Read/write grants for each supported service. Format a drive while adding it as a volume, update a CIFS share's connection details, and see each volume's availability, free space and source errors on the same page. Managed local folders and backup targets survive server restarts on the data drive. Deleting a volume permanently removes managed local data but preserves external-drive and network-share contents.
- Attached-drive lists update automatically. Shared-volume status, free space and source errors refresh after drive and network changes, with mounted shares following the kernel's connection state and periodic free-space checks. Service and backup mount requests reject disconnected shares without tearing down active mounts. Services refresh shared-volume mounts after drive replacement, older attachment cleanup leaves replacement mounts usable, and healthy idle shares avoid repeated network connections.
- Keep unsaved names, folder edits and discard warnings while volume, backup-target or drive updates arrive. Clear vanished drive or partition choices without automatically selecting formatting; removal or changed drive details during erase confirmation require a fresh choice. CIFS connection changes notify reactive services; existing mounts keep their source until remounted or restarted.
- Services can treat missing registered folders as unavailable without accepting invalid mount requests.
- Manage volumes and backup targets by name, with source errors highlighted in red and a loading state while backup history is fetched. Find existing backups on connected drives without re-entering paths; stored CIFS targets and credentials carry forward automatically.
- Back up volumes independently of services and restore them as new local copies without overwriting existing data. Backup destinations cannot overlap source folders through case variations or local directory aliases. Failed local-target cleanup remains registered for retry.
