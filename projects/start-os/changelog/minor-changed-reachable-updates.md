- The Updates tab offers each installed service the newest version it can install, including the next step when a service must update in steps, and the Marketplace opens a service's page on that version.
- The Marketplace lists versions that need a newer StartOS. Their install and update buttons are disabled with a note to update your server first, and the Marketplace explains when your installed version cannot update directly to the selected version.
- An update in the Updates tab shows the release notes of every version since the installed one, newest first.
