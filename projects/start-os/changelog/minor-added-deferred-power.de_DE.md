- **Bei Neustart oder Herunterfahren während einer Sicherung kann deren Abschluss abgewartet werden.** Der Dialog bleibt bis zur Auswahl oder zum Schließen offen. Eine Leiste zeigt die vorgemerkte Aktion und erlaubt das Abbrechen. Auch der physische Einschaltknopf wartet auf die Sicherung, wenn StartOS ihn abfangen kann. Die CLI-Befehle `start-cli server restart` und `server shutdown` warten standardmäßig; `--force` unterbricht die Sicherung. `start-cli server cancel-deferred-power` bricht die vorgemerkte Aktion ab. Sobald Neustart oder Herunterfahren feststeht, lehnt StartOS neue Sicherungen ab. Siehe [Sicherungen erstellen](https://docs.start9.com/start-os/backup-create.html).
