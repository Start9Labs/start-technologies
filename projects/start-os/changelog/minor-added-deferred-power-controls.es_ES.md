- El botón físico también espera si StartOS puede interceptarlo. `start-cli server restart` y `server shutdown` esperan por defecto; `--force` interrumpe la copia. `start-cli server cancel-deferred-power` cancela la acción pendiente. Una vez confirmado el inicio del reinicio o apagado, StartOS rechaza nuevas copias. Consulta [Crear copias de seguridad](https://docs.start9.com/start-os/backup-create.html).
