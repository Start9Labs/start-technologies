- Le bouton physique attend aussi lorsque StartOS peut intercepter son action. `start-cli server restart` et `server shutdown` attendent par défaut ; `--force` interrompt la sauvegarde. `start-cli server cancel-deferred-power` annule l’action en attente. Dès que le redémarrage ou l’arrêt est engagé, StartOS refuse les nouvelles sauvegardes. Voir [Créer des sauvegardes](https://docs.start9.com/start-os/backup-create.html).
