- **Ponowne uruchomienie lub wyłączenie podczas kopii zapasowej pozwala poczekać na jej zakończenie.** Okno pozostaje otwarte do wyboru lub zamknięcia. Pasek pokazuje oczekującą operację i pozwala ją anulować. Przycisk fizyczny również czeka, jeśli StartOS może przechwycić jego działanie. `start-cli server restart` i `server shutdown` domyślnie czekają; `--force` przerywa kopię. `start-cli server cancel-deferred-power` anuluje oczekującą operację. Po rozpoczęciu restartu lub wyłączenia StartOS odmawia nowych kopii. Zobacz [Tworzenie kopii zapasowych](https://docs.start9.com/start-os/backup-create.html).
