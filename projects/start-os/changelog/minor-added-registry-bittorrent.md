- Add optional BitTorrent downloads for marketplace packages and routine OS updates. When enabled, advertised torrents are preferred with HTTP fallback. **System → Software sharing** controls downloads and sharing compatible installed S9PKs and stored OS images; both default off. Incoming peers opt in through initially-off public-address rows. A stopped settings watcher is reported on the page; restart StartOS to restore peer transfers. It shows the StartOS default gateway and reuses native Address Requirements and PCP/UPnP forwarding, without extra payload copies or extended retention.
