## Novedades

- Added opt-in background conversion of existing backups to the authenticated filesystem format, with weighted overall progress, all phases listed upfront, explicit resumption after interruption, and success or failure notifications naming the target. Creating a backup offers to update this server’s older format or skip conversion; restoring marks each old-format server backup with an explanatory warning tag. Unconverted backups remain usable for backups and restores.

- Added named read-only snapshots to the `startos-backup-fs` utility, with explicit creation, listing, deletion, and recovery mounts. Snapshots share unchanged data and retain earlier versions as the current backup changes; retention is managed manually.

- Los tokens de portador permiten usar clientes de API que no pueden firmar solicitudes. `start-cli auth token create --name <name>` muestra el token una sola vez; las solicitudes con `Authorization: Bearer <token>` se autentican como una sesión con ese nombre, visible y revocable en la lista de sesiones. Los tokens inactivos durante 30 días se revocan como las demás sesiones.

- Nuevo servidor MCP en `/mcp`: los agentes de IA y otros clientes MCP pueden llamar a la API de StartOS como herramientas mediante el transporte HTTP transmisible, autenticándose con un token de portador de `start-cli auth token create`.

- Nuevo `package.exec` en la API, también disponible como herramienta MCP: ejecuta un comando en el subcontenedor de un servicio hasta que termina y devuelve su salida y código de salida, con entrada estándar y tiempo límite opcionales.

- Gestiona conjuntos de claves de confianza con nombre en una tabla adaptable de Sistema con menús de edición y eliminación por fila y confianza independiente para paquetes y actualizaciones del SO. Los nuevos conjuntos confían solo en paquetes por defecto. Importa claves públicas Ed25519 en PEM o GPG con armadura ASCII, respetando las revocaciones de los archivos GPG y conservando los certificados completos con nombres y direcciones de correo electrónico. Los conjuntos integrados aparecen primero, con nombres de solo lectura y sin opción de eliminar; ambos controles de confianza siguen disponibles.
- Cambia el nombre de Claves SSH a Acceso SSH.
- Muestra los firmantes de confianza, bloquea las instalaciones de Marketplace sin confianza y pide confirmación explícita para instalar manualmente software sin confianza.
- Las instalaciones de paquetes y actualizaciones del SO por CLI requieren firmantes de confianza por defecto; `--trust` omite explícitamente ese requisito sin desactivar las comprobaciones de firma e integridad.

- Activa las notificaciones push desde el diálogo de ajustes de Notificaciones para recibir avisos de StartOS con la interfaz cerrada, incluidos los endpoints UnifiedPush autoalojados que proporcione el navegador.

- **Formatear una unidad de copia de seguridad desde StartOS.** En `Sistema > Crear copia de seguridad`, «Formatear una unidad» borra una unidad conectada y la deja con una única partición Btrfs preparada para copias de seguridad. Se rechaza la unidad que contiene StartOS o sus datos. También está disponible como `start-cli disk format`.

- Las actualizaciones de seguridad compatibles anunciadas por el registro del SO seleccionado aparecen en Notificaciones y usan las notificaciones push del navegador cuando están activadas. Su enlace de actualización de software abre Sistema → General.
- Las actualizaciones beta pueden reemplazar una compilación anterior con la misma versión del SO.

- Almacena claves con tipos estructurales sin la envoltura PEM, conservando los inicios de sesión existentes y los firmantes de actualizaciones de confianza durante las actualizaciones.

- La tarjeta «Dependencias» de un servicio muestra la versión instalada de cada dependencia. Una dependencia con una versión incompatible abre el Mercado en una versión compatible.

- Starting and loading health checks can show a clock while waiting for an external condition. All health statuses display nonempty service-provided messages as-is; empty messages use the status label.

- Las conexiones de servicios HTTP sin cifrar pasan por StartOS cuando el proxy HTTP está habilitado. Las aplicaciones ven StartOS como extremo TCP; las direcciones de los clientes están disponibles en `X-Forwarded-For` cuando se habilita la generación de cabeceras reenviadas.

- Las conexiones TLS directas de servicios que no requieren proxy HTTP conservan las direcciones IP de origen de los clientes.

- Prevented stale backup data beyond a file's saved length from reappearing when the file grows after an interrupted write.

- Allow retrying an interrupted first backup when no encryption key was saved, reclaiming its unusable encrypted data through the target trash.
- Prevent concurrent first opens from publishing different encryption keys for the same backup store.

- Recupera bloques de asignación sin usar de la unidad de datos mediante un equilibrado Btrfs inicial en segundo plano tras actualizar y un mantenimiento semanal posterior.
- Avisa cuando queda poco espacio para asignar metadatos en la unidad de datos, antes de que los servicios sufran errores de escritura aunque se indique que hay espacio libre.

- Las copias de seguridad y la recuperación mediante carpetas de red aceptan nombres de host DNS con puntos. Los nombres de equipo sin dominio siguen usando exclusivamente NetBIOS, y los errores de resolución indican el resolvedor utilizado.

- Acepta cambios del entorno de subcontenedores mediante `JSON_ENV_*`, incluidos valores multilínea y eliminación de variables.
- Conserva valores multilínea predeterminados de la imagen en `package attach`.
- Respeta la eliminación explícita de `HOME` sin restaurar su valor predeterminado.

- **Novedades en tu idioma.** Las novedades y el enlace al registro completo de cambios usan el idioma del servidor antes y después de una actualización. Si no hay traducción disponible, las novedades se muestran en inglés.
- **Enlace correcto al registro completo de cambios.** La notificación de bienvenida enlaza al registro de cambios publicado en lugar de a una copia desactualizada.

- Se corrigió un problema por el que el Mercado se quedaba cargando al abrir enlaces de dependencias.

- Backups to network shares are much faster, especially over high-latency links such as remote sites reached through StartTunnel. Backup data is now written in large batches with many requests in flight, instead of waiting for a network round trip on each small write.

- Al actualizar desde StartOS 0.3.5, cada dirección `.onion` conserva los puertos que servía allí, también para los servicios que terminan de migrar después de Tor. Una interfaz que no tenía dirección Tor en 0.3.5 no recibe ninguna.

- **Los comandos con entrada por tubería terminan cuando finaliza su entrada.** Los comandos como `cat` ejecutados mediante `package attach` reciben EOF de la entrada estándar por tubería o redirigida y finalizan con normalidad.

- La interfaz ya no se queda atascada después de una actualización de StartOS. El diálogo de actualización necesaria muestra el progreso de la sincronización de la interfaz, ofrece Actualizar al completarse y permite recuperarse si la sincronización falla o se atasca.

- **Añadir dominios públicos a interfaces con rangos de puertos.** Los servicios cuyas interfaces exponen un rango de puertos permiten añadir dominios públicos desde la interfaz web o la CLI.
- Los rangos de puertos habilitados conservan la asignación de sus dominios configurados al comprobar si hay duplicados.

- Al eliminar una puerta de enlace también se borran las selecciones de direcciones que los servicios hicieron en ella.

- Gateways selected for outbound traffic by the server or a service must be deselected before removal, preventing removal from cutting off outbound connectivity.

- Al añadir un túnel, se informa de un error tras 30 segundos si su interfaz de red sigue sin estar disponible, en lugar de esperar indefinidamente.

- La interfaz ofrece acciones de recuperación si su copia en caché está dañada.
- La interfaz detecta antes su propia actualización después de actualizar StartOS.

## Seguridad

- Strengthened backup encryption authentication and password-protected key wrapping, and removed backup encryption keys from process arguments and recovery errors. Authenticated current references reject substitutions of individual stored records; rollback to a genuine older complete backup view remains possible. Existing backups remain usable for backups and restores until explicit conversion. Conversion rewrites encrypted data, resumes after interruption, and prevents older StartOS releases from reading the converted target.

- La política de autenticación del proxy HTTP, cuando está configurada, se aplica tanto a conexiones de servicios sin cifrar como a conexiones TLS.

- Los sitios web que visita ya no pueden usar su navegador para controlar un servidor que se está configurando o que está en modo de diagnóstico. Durante la configuración y el diagnóstico, abra el servidor mediante su dirección `.local` o su dirección IP. Gracias a dritzps por informarlo.

- node-forge se ha actualizado a la versión 1.4.2.

- Los paquetes del sistema de los contenedores de servicios incluyen las correcciones de seguridad disponibles de Debian, incluida la del decodificador Brotli.

## Important

Existing OS-update trust selections are preserved during migration. If individual Start9 keys were removed, the remaining trusted keys are retained as separate entries rather than enabling the complete Start9 group for OS updates.

Production Marketplace packages must be re-signed with an enabled Start9 key before rollout. Packages signed only by Start9 Alpha or other untrusted keys remain blocked unless their publisher is explicitly enabled.

- Clients of an HTTP-proxied service with configured authentication must provide those credentials on plaintext connections too.

- Services with HTTP proxying enabled now see StartOS as their TCP peer on plaintext connections. Client addresses are available through `X-Forwarded-For` when the binding enables header generation.

- Downgrading to an earlier StartOS version restores that version's HTTP authentication behavior, including its unprotected plaintext connections. Downgrades are blocked for HTTP authentication policies without a TLS wrapper; add TLS to those bindings before downgrading.
