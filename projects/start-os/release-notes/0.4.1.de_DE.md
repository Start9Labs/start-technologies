## Neuerungen

- Added opt-in background conversion of existing backups to the authenticated filesystem format, with weighted overall progress, all phases listed upfront, explicit resumption after interruption, and success or failure notifications naming the target. Creating a backup offers to update this server’s older format or skip conversion; restoring marks each old-format server backup with an explanatory warning tag. Unconverted backups remain usable for backups and restores.

- Added named read-only snapshots to the `startos-backup-fs` utility, with explicit creation, listing, deletion, and recovery mounts. Snapshots share unchanged data and retain earlier versions as the current backup changes; retention is managed manually.

- Bearer-Token unterstützen API-Clients, die keine Anfragen signieren können. `start-cli auth token create --name <name>` gibt ein Token einmalig aus; Anfragen mit `Authorization: Bearer <token>` authentifizieren sich als Sitzung dieses Namens, die in der Sitzungsliste angezeigt und widerrufen werden kann. Wie andere Sitzungen werden Token nach 30 Tagen Inaktivität widerrufen.

- Neuer MCP-Server unter `/mcp`: KI-Agenten und andere MCP-Clients können die StartOS-API über den Streamable-HTTP-Transport als Werkzeuge aufrufen und authentifizieren sich mit einem Bearer-Token aus `start-cli auth token create`.

- Neu in der API ist `package.exec`, auch als MCP-Werkzeug verfügbar: Es führt einen Befehl im Subcontainer eines Dienstes bis zum Ende aus und gibt Ausgabe und Exit-Code zurück, optional mit Standardeingabe und Zeitlimit.

- Benannte vertrauenswürdige Schlüsselbünde lassen sich in einer responsiven Systemtabelle über Zeilenmenüs bearbeiten und löschen. Die Vertrauensschalter für Pakete und OS-Updates sind unabhängig; neue Schlüsselbünde vertrauen standardmäßig nur Paketen. Öffentliche Ed25519-Schlüssel lassen sich als PEM oder ASCII-armiertes GPG importieren; Widerrufe in GPG-Exporten werden berücksichtigt und vollständige Zertifikate mit Namen und E-Mail-Adressen aufbewahrt. Eingebaute Schlüsselbünde stehen zuerst, ihre Namen sind schreibgeschützt und die Löschoption ist ausgeblendet; beide Vertrauensschalter bleiben änderbar.
- SSH-Schlüssel wird in SSH-Zugriff umbenannt.
- Vertrauenswürdige Paket-Signierer werden angezeigt; nicht vertrauenswürdige Marketplace-Installationen werden blockiert und das manuelle Installieren nicht vertrauenswürdiger Software erfordert eine ausdrückliche Bestätigung.
- CLI-Paketinstallationen und OS-Updates erfordern standardmäßig vertrauenswürdige Signierer. `--trust` überschreibt diese Vertrauensanforderung ausdrücklich, ohne Signatur- oder Integritätsprüfungen auszuschalten.

- Push im Einstellungsdialog der Benachrichtigungsseite aktivieren, um StartOS-Benachrichtigungen auch bei geschlossener Oberfläche zu erhalten, einschließlich selbst gehosteter UnifiedPush-Endpunkte, die der Browser bereitstellt.

- **Ein Sicherungslaufwerk in StartOS formatieren.** Unter `System > Sicherung erstellen` löscht „Laufwerk formatieren“ ein angeschlossenes Laufwerk und richtet darauf eine einzelne Btrfs-Partition für Sicherungen ein. Das Laufwerk mit StartOS oder dessen Daten ist ausgeschlossen. Auch als `start-cli disk format` verfügbar.

- Kompatible Sicherheitsupdates, die Ihre ausgewählte OS-Registry ankündigt, erscheinen unter Benachrichtigungen und werden bei aktivierter Browser-Push-Funktion zugestellt. Ihr Software-Update-Link öffnet System → Allgemein.
- Beta-Updates können einen früheren Build mit derselben OS-Version ersetzen.

- Strukturell typisierte Schlüssel werden ohne PEM-Hülle gespeichert; bestehende Anmeldungen und vertrauenswürdige Signaturschlüssel für Updates bleiben beim Upgrade erhalten.

- Die Karte „Abhängigkeiten“ eines Dienstes zeigt die installierte Version jeder Abhängigkeit. Eine Abhängigkeit mit inkompatibler Version öffnet den Marktplatz bei einer kompatiblen Version.

- Starting and loading health checks can show a clock while waiting for an external condition. All health statuses display nonempty service-provided messages as-is; empty messages use the status label.

- Unverschlüsselte Dienstverbindungen werden bei aktiviertem HTTP-Proxy über StartOS geleitet. Anwendungen sehen StartOS als TCP-Gegenstelle; bei aktivierter Erzeugung weitergeleiteter Header stehen Client-IP-Adressen in `X-Forwarded-For` bereit.

- Rohe TLS-Verbindungen zu Diensten, die keinen HTTP-Proxy benötigen, behalten die Quell-IP-Adressen der Clients.

- Prevented stale backup data beyond a file's saved length from reappearing when the file grows after an interrupted write.

- Allow retrying an interrupted first backup when no encryption key was saved, reclaiming its unusable encrypted data through the target trash.
- Prevent concurrent first opens from publishing different encryption keys for the same backup store.

- Ungenutzte Chunks auf dem Datenlaufwerk werden nach dem Update durch einen ersten Btrfs-Balance-Lauf im Hintergrund und anschließend durch wöchentliche Wartung freigegeben.
- Eine Warnung erscheint, wenn der für Metadaten zuweisbare Platz auf dem Datenlaufwerk knapp wird, bevor Dienste trotz gemeldeten freien Speicherplatzes Schreibfehler erhalten.

- Sicherungen und Wiederherstellung über Netzwerkordner akzeptieren DNS-Hostnamen mit Punkten. Kurze Computernamen verwenden weiterhin ausschließlich NetBIOS; Fehlermeldungen bei der Namensauflösung nennen den verwendeten Resolver.

- Umgebungsvariablen von Untercontainern lassen sich über `JSON_ENV_*` überschreiben, einschließlich mehrzeiliger Werte und des Entfernens von Variablen.
- `package attach` erhält mehrzeilige Standardwerte der Image-Umgebung.
- Ein ausdrücklich entferntes `HOME` wird nicht mit seinem Standardwert wiederhergestellt.

- **Neuerungen in Ihrer Sprache.** Die Neuerungen und der Verweis auf das vollständige Änderungsprotokoll erscheinen vor und nach einem Update in der Sprache des Servers. Wenn keine Übersetzung verfügbar ist, erscheinen die Neuerungen auf Englisch.
- **Funktionierender Link zum vollständigen Änderungsprotokoll.** Die Willkommensbenachrichtigung verweist auf das veröffentlichte Änderungsprotokoll statt auf eine veraltete Kopie.

- Behoben, dass der Marktplatz beim Öffnen über Abhängigkeitslinks dauerhaft lädt.

- Backups to network shares are much faster, especially over high-latency links such as remote sites reached through StartTunnel. Backup data is now written in large batches with many requests in flight, instead of waiting for a network round trip on each small write.

- Beim Update von StartOS 0.3.5 behält jede `.onion`-Adresse die Ports, die sie dort bediente, auch bei Diensten, deren Migration erst nach Tor abgeschlossen ist. Eine Schnittstelle ohne Tor-Adresse unter 0.3.5 erhält keine.

- **Befehle mit Pipe-Eingabe enden, sobald ihre Eingabe endet.** Befehle wie `cat`, die über `package attach` ausgeführt werden, erhalten EOF von der per Pipe oder Umleitung bereitgestellten Standardeingabe und beenden sich normal.

- Die Oberfläche bleibt nach einem StartOS-Update nicht mehr beim Aktualisieren hängen. Der Dialog „Aktualisierung erforderlich“ zeigt die Synchronisierung der Benutzeroberfläche, bietet danach „Aktualisieren“ an und ermöglicht die Wiederherstellung, wenn die Synchronisierung fehlschlägt oder hängen bleibt.

- **Öffentliche Domains zu Schnittstellen mit Portbereichen hinzufügen.** Für Dienste, deren Schnittstellen einen Portbereich bereitstellen, lassen sich öffentliche Domains über die Weboberfläche oder die CLI hinzufügen.
- Aktivierte Portbereiche behalten bei der Prüfung auf Duplikate die Zuordnung ihrer konfigurierten Domains.

- Beim Entfernen eines Gateways werden auch die Adressauswahlen gelöscht, die Dienste für dieses Gateway getroffen haben.

- Gateways selected for outbound traffic by the server or a service must be deselected before removal, preventing removal from cutting off outbound connectivity.

- Das Hinzufügen eines Tunnels meldet nach 30 Sekunden einen Fehler, wenn seine Netzwerkschnittstelle nicht verfügbar wird, statt unbegrenzt zu warten.

- Die Oberfläche bietet Wiederherstellungsaktionen an, wenn ihre zwischengespeicherte Kopie beschädigt ist.
- Nach einem StartOS-Update übernimmt die Oberfläche ihre eigene Aktualisierung schneller.

## Sicherheit

- Strengthened backup encryption authentication and password-protected key wrapping, and removed backup encryption keys from process arguments and recovery errors. Authenticated current references reject substitutions of individual stored records; rollback to a genuine older complete backup view remains possible. Existing backups remain usable for backups and restores until explicit conversion. Conversion rewrites encrypted data, resumes after interruption, and prevents older StartOS releases from reading the converted target.

- Eine konfigurierte HTTP-Proxy-Authentifizierungsrichtlinie gilt für unverschlüsselte und für TLS-Verbindungen zu Diensten.

- Besuchte Websites können Ihren Browser nicht mehr nutzen, um einen Server zu steuern, der gerade eingerichtet wird oder sich im Diagnosemodus befindet. Öffnen Sie den Server während der Einrichtung und Diagnose über seine `.local`-Adresse oder IP-Adresse. Vielen Dank an dritzps für die Meldung.

- node-forge wurde auf Version 1.4.2 aktualisiert.

- Die Systempakete der Dienstcontainer enthalten die verfügbaren Debian-Sicherheitskorrekturen, einschließlich der Korrektur für den Brotli-Decoder.

## Important

Existing OS-update trust selections are preserved during migration. If individual Start9 keys were removed, the remaining trusted keys are retained as separate entries rather than enabling the complete Start9 group for OS updates.

Production Marketplace packages must be re-signed with an enabled Start9 key before rollout. Packages signed only by Start9 Alpha or other untrusted keys remain blocked unless their publisher is explicitly enabled.

- Clients of an HTTP-proxied service with configured authentication must provide those credentials on plaintext connections too.

- Services with HTTP proxying enabled now see StartOS as their TCP peer on plaintext connections. Client addresses are available through `X-Forwarded-For` when the binding enables header generation.

- Downgrading to an earlier StartOS version restores that version's HTTP authentication behavior, including its unprotected plaintext connections. Downgrades are blocked for HTTP authentication policies without a TLS wrapper; add TLS to those bindings before downgrading.
