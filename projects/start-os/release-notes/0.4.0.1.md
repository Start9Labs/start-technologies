**A maintenance release for 0.4.0**, repairing the update from 0.3.5.1 and installation on the Server Pure and the Raspberry Pi. If you are already on 0.4.0, it is an ordinary update.

## ⚠️ Updating from 0.3.5.1

> **The only way to update from 0.3.5.1 is by following the [0.4.0 Update Guide](https://docs.start9.com/start-os/update-040.html) precisely.** This is a sensitive update between two essentially distinct operating systems — skipping steps or improvising can result in data loss.
>
> If anything goes wrong, **stop and [contact support](https://start9.com/contact)** — do not attempt to troubleshoot on your own.

## Highlights

- **Tor comes across from 0.3.5.1 and starts on its own** — your existing onion addresses answer as soon as the update finishes, with nothing to start by hand.
- **A service that fails to migrate tells you why** — the notification for that service carries the error that stopped it, alongside the summary listing everything to re-install. Services that changed id on 0.4.0 — Ghost, Synapse, Monero, Nostr and Fedimint — no longer appear among the failures.
- **The over-the-air update reaches 0.4.0 on the Server Pure.** A Server Pure running an older PureBoot release also applies its firmware update on the next start.
- **Installing onto a pre-installed Raspberry Pi keeps the data pool you pick.**
- **A service that serves its own TLS certificate is now served like any other TLS port** — StartOS routes it by SNI with your address preserved, so the service's domains are advertised on its preferred port, usually 443. Such a port accepts TLS connections only and no longer relays UDP; the port number is unchanged, so existing addresses, bookmarks and router forwards keep working.
- **The StartOS web interface holds ports 80 and 443.**

## Important

Backups taken before 0.4.0 cannot be restored onto it. After updating, update all of your services and create a fresh backup.
