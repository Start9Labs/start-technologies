**0.4.1 adds automatic backup schedules and checkpoint history.**

## Highlights

- Schedule unattended backups for selected services and System data, with a timezone and hourly, daily, weekly, or monthly frequency.
- Keep automatic checkpoints separately from the latest manual backup, inspect their history, and restore selected service checkpoints.
- Preview retention changes before applying them. Failed backup locations produce notifications, and repeated failures pause affected schedules.

## Important

- Applying retention or deleting checkpoints permanently removes the selected backup data. Review the retention preview before applying it.
