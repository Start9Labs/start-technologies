**0.4.1 adds bearer tokens for API clients, improves service packaging and legacy package conversion, updates the NVIDIA driver, and keeps service-to-service IPv6 access available.**

## Highlights

- **API clients can authenticate with bearer tokens.** `start-cli auth token create --name <name>` issues a token that acts as a named session: it is listed and revoked under Active Sessions and expires after 30 days unused.
- **Legacy service packages convert with built-in SquashFS support**, preserving container filesystem ownership and permissions.
- **The bundled start-cli packs services and adds container images with built-in SquashFS support.** Packaged JavaScript remains readable by the service runtime without changing source permissions, and manifest paths containing apostrophes work during packing and validation.
- **NVIDIA images include driver 580.178.04**, with Linux 7.2 compatibility.
- **Service-to-service IPv6 access stays available** through the internal bridge address while you change access from other networks.
