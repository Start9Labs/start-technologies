**0.4.1 adds bearer tokens for API clients and fixes command input and service networking.**

## Highlights

- **API clients can authenticate with bearer tokens.** `start-cli auth token create --name <name>` issues a token that acts as a named session: it is listed and revoked under Active Sessions and expires after 30 days unused.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
- **Add public domains to port-range interfaces.** Services whose interfaces expose a range of ports can add public domains from the web UI or CLI.
