StartOS 0.4.1 adds shared management of trusted software-signing keys for service packages and OS updates.

## Highlights

- Manage trusted keys from the Marketplace registry selector or the Software Update card. The entries are shared, with independent trust switches for packages and OS updates.
- Start9 is enabled by default; Start9 Alpha is available but disabled. Custom entries can contain multiple PEM-encoded Ed25519 public keys.
- Package details show trusted signers. Untrusted Marketplace installs are blocked; sideloading untrusted software requires explicit confirmation.
- CLI package installs and OS updates require trusted signers by default. Use `--trust` only when deliberately accepting an untrusted signer; signature and integrity checks still apply.

## Important

Existing OS-update trust selections are preserved during migration. If individual Start9 keys were removed, the remaining trusted keys are retained as separate entries rather than enabling the complete Start9 group for OS updates.

Production Marketplace packages must be re-signed with an enabled Start9 key before rollout. Packages signed only by Start9 Alpha or other untrusted keys remain blocked unless their publisher is explicitly enabled.
