## Nouveautés

- Added opt-in background conversion of existing backups to the authenticated filesystem format, with weighted overall progress, all phases listed upfront, explicit resumption after interruption, and success or failure notifications naming the target. Creating a backup offers to update this server’s older format or skip conversion; restoring marks each old-format server backup with an explanatory warning tag. Unconverted backups remain usable for backups and restores.

- Added named read-only snapshots to the `startos-backup-fs` utility, with explicit creation, listing, deletion, and recovery mounts. Snapshots share unchanged data and retain earlier versions as the current backup changes; retention is managed manually.

- Les jetons bearer permettent aux clients API incapables de signer leurs requêtes de s’authentifier. `start-cli auth token create --name <name>` affiche le jeton une seule fois ; les requêtes avec `Authorization: Bearer <token>` utilisent une session portant ce nom, visible et révocable dans la liste des sessions. Les jetons inactifs pendant 30 jours sont révoqués comme les autres sessions.

- Nouveau serveur MCP sur `/mcp` : les agents d'IA et autres clients MCP peuvent appeler l'API de StartOS comme outils via le transport HTTP diffusable, en s'authentifiant avec un jeton porteur issu de `start-cli auth token create`.

- Nouveau `package.exec` dans l'API, également proposé comme outil MCP : il exécute une commande dans le sous-conteneur d'un service jusqu'à son terme et renvoie sa sortie et son code de sortie, avec entrée standard et délai facultatifs.

- Gérez des trousseaux de confiance nommés dans un tableau Système adaptatif avec des menus de modification et de suppression par ligne et des choix de confiance indépendants pour les paquets et le système. Les nouveaux trousseaux approuvent uniquement les paquets par défaut. Importez des clés publiques Ed25519 au format PEM ou GPG avec armure ASCII, en respectant les révocations des exports GPG et en conservant les certificats complets avec les noms et adresses e-mail. Les trousseaux intégrés restent en premier, avec des noms en lecture seule et sans option de suppression ; les deux choix de confiance restent modifiables.
- Renomme Clés SSH en Accès SSH.
- Affiche les signataires de paquets de confiance, bloque les installations Marketplace non approuvées et exige une confirmation explicite pour l’installation manuelle de logiciels non approuvés.
- Les installations de paquets et mises à jour du système en CLI exigent des signataires de confiance par défaut ; `--trust` outrepasse explicitement cette exigence sans désactiver les vérifications de signature et d’intégrité.

- Activez les notifications push depuis la fenêtre des paramètres de Notifications pour recevoir les notifications StartOS lorsque l’interface est fermée, y compris via les points de terminaison UnifiedPush auto-hébergés fournis par le navigateur.

- **Formater un disque de sauvegarde depuis StartOS.** Dans `Système > Créer une sauvegarde`, « Formater un disque » efface un disque connecté et y crée une seule partition Btrfs prête pour les sauvegardes. Le disque contenant StartOS ou ses données est refusé. Également disponible avec `start-cli disk format`.

- Les mises à jour de sécurité compatibles annoncées par le registre du système sélectionné apparaissent dans Notifications et utilisent les notifications push du navigateur lorsqu’elles sont activées. Leur lien de mise à jour du logiciel ouvre Système → Général.
- Les mises à jour bêta peuvent remplacer une compilation antérieure portant le même numéro de version du système.

- Stocke les clés typées structurellement sans enveloppe PEM, tout en préservant les connexions existantes et les signataires de mises à jour approuvés lors des mises à niveau.

- La carte « Dépendances » d’un service affiche la version installée de chaque dépendance. Une dépendance dont la version est incompatible ouvre la Bibliothèque de services sur une version compatible.

- Starting and loading health checks can show a clock while waiting for an external condition. All health statuses display nonempty service-provided messages as-is; empty messages use the status label.

- Les connexions de services HTTP non chiffrées passent par StartOS lorsque le proxy HTTP est activé. Les applications voient StartOS comme pair TCP ; les adresses IP des clients sont disponibles dans `X-Forwarded-For` lorsque la génération des en-têtes de transfert est activée.

- Les connexions TLS brutes des services ne nécessitant pas de proxy HTTP conservent les adresses IP sources des clients.

- Prevented stale backup data beyond a file's saved length from reappearing when the file grows after an interrupted write.

- Allow retrying an interrupted first backup when no encryption key was saved, reclaiming its unusable encrypted data through the target trash.
- Prevent concurrent first opens from publishing different encryption keys for the same backup store.

- Récupère les groupes de blocs inutilisés du disque de données grâce à un premier équilibrage Btrfs en arrière-plan après la mise à jour, puis à une maintenance hebdomadaire.
- Avertit lorsque l'espace disponible pour l'allocation des métadonnées du disque de données devient faible, avant que les services ne rencontrent des erreurs d'écriture malgré l'espace libre annoncé.

- Les sauvegardes et la restauration dans des dossiers réseau acceptent les noms d'hôte DNS contenant des points. Les noms d'ordinateur simples restent limités à NetBIOS, et les erreurs de résolution indiquent le résolveur utilisé.

- Accepte les substitutions de variables d’environnement des sous-conteneurs via `JSON_ENV_*`, y compris les valeurs multilignes et la suppression de variables.
- Préserve les valeurs multilignes par défaut de l’image dans `package attach`.
- Respecte la suppression explicite de `HOME` sans rétablir sa valeur par défaut.

- **Les nouveautés dans votre langue.** Les nouveautés et le lien vers le journal complet des modifications utilisent la langue du serveur avant et après une mise à jour. Si aucune traduction n'est disponible, les nouveautés s'affichent en anglais.
- **Un lien correct vers le journal complet des modifications.** La notification de bienvenue renvoie au journal des modifications publié plutôt qu'à une copie obsolète.

- Correction des liens de dépendances qui laissaient la Bibliothèque de services bloquée sur le chargement.

- Backups to network shares are much faster, especially over high-latency links such as remote sites reached through StartTunnel. Backup data is now written in large batches with many requests in flight, instead of waiting for a network round trip on each small write.

- La mise à jour depuis StartOS 0.3.5 conserve à chaque adresse `.onion` les ports qu'elle servait, y compris pour les services dont la migration se termine après celle de Tor. Une interface sans adresse Tor sous 0.3.5 n'en reçoit pas.

- **Les commandes alimentées par un tube se terminent à la fin de leur entrée.** Les commandes comme `cat` exécutées via `package attach` reçoivent EOF de l'entrée standard fournie par un tube ou une redirection et se terminent normalement.

- L’interface ne reste plus bloquée après une mise à jour de StartOS. Le dialogue « Actualisation nécessaire » affiche la progression de la synchronisation de l’interface, propose Rafraîchir une fois celle-ci terminée et offre des actions de récupération si la synchronisation échoue ou reste bloquée.

- **Ajouter des domaines publics aux interfaces avec des plages de ports.** Pour les services dont les interfaces exposent une plage de ports, il est possible d'ajouter des domaines publics depuis l'interface web ou la CLI.
- Les plages de ports activées conservent l'attribution de leurs domaines configurés lors de la recherche de doublons.

- La suppression d'une passerelle efface aussi les choix d'adresses que les services y avaient faits.

- Gateways selected for outbound traffic by the server or a service must be deselected before removal, preventing removal from cutting off outbound connectivity.

- L'ajout d'un tunnel signale une erreur après 30 secondes si son interface réseau reste indisponible, au lieu d'attendre indéfiniment.

- L’interface propose des actions de récupération lorsque sa copie en cache est corrompue.
- L’interface prend en compte sa propre mise à jour plus rapidement après une mise à jour de StartOS.

## Sécurité

- Strengthened backup encryption authentication and password-protected key wrapping, and removed backup encryption keys from process arguments and recovery errors. Authenticated current references reject substitutions of individual stored records; rollback to a genuine older complete backup view remains possible. Existing backups remain usable for backups and restores until explicit conversion. Conversion rewrites encrypted data, resumes after interruption, and prevents older StartOS releases from reading the converted target.

- Lorsqu’une politique d’authentification du proxy HTTP est configurée, elle s’applique aux connexions de services non chiffrées comme aux connexions TLS.

- Les sites web que vous visitez ne peuvent plus utiliser votre navigateur pour contrôler un serveur en cours de configuration ou en mode diagnostic. Pendant la configuration et le diagnostic, ouvrez le serveur via son adresse `.local` ou son adresse IP. Merci à dritzps de l’avoir signalé.

- node-forge est mis à jour vers la version 1.4.2.

- Les paquets système des conteneurs de services incluent les correctifs de sécurité Debian disponibles, dont celui du décodeur Brotli.

## Important

Existing OS-update trust selections are preserved during migration. If individual Start9 keys were removed, the remaining trusted keys are retained as separate entries rather than enabling the complete Start9 group for OS updates.

Production Marketplace packages must be re-signed with an enabled Start9 key before rollout. Packages signed only by Start9 Alpha or other untrusted keys remain blocked unless their publisher is explicitly enabled.

- Clients of an HTTP-proxied service with configured authentication must provide those credentials on plaintext connections too.

- Services with HTTP proxying enabled now see StartOS as their TCP peer on plaintext connections. Client addresses are available through `X-Forwarded-For` when the binding enables header generation.

- Downgrading to an earlier StartOS version restores that version's HTTP authentication behavior, including its unprotected plaintext connections. Downgrades are blocked for HTTP authentication policies without a TLS wrapper; add TLS to those bindings before downgrading.
