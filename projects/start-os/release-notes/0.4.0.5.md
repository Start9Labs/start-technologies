**0.4.0.5 is a maintenance release improving interface updates and command input through `package attach`.**

## Highlights

- **Interface refresh shows update status and recovery actions.** The Refresh Needed dialog tracks interface downloads and offers retry and cache reset when needed. Refreshing the page requires an explicit Refresh click.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
