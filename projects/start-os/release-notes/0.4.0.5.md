**0.4.0.5 is a security release for service HTTP authentication.**

## Highlights

- **HTTP authentication covers both connection types.** Service HTTP proxy authentication policies apply to plaintext and TLS connections.
- **Raw TLS services retain client addresses.** Services using raw TLS without HTTP proxying receive the original client source IP address.

## Important

- Plaintext HTTP services now see StartOS as their TCP peer. Client addresses are available through `X-Forwarded-For` when the binding enables header generation.

- Downgrading to an earlier StartOS version restores that version's HTTP authentication behavior, including its unprotected plaintext connections. Downgrades are blocked for HTTP authentication policies without a TLS wrapper; add TLS to those bindings before downgrading.
