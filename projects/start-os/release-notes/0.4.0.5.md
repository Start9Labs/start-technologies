**0.4.0.5 is a maintenance release improving network-folder backups and command input through `package attach`.**

## Highlights

- Network folders accept dotted DNS hostnames, including names provided by a router across subnets. Bare computer names remain NetBIOS-only.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
