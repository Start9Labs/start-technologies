**0.4.0.5 is a maintenance release improving post-update notifications, command input, and service networking.**

## Highlights

- **Welcome details in your language.** Release highlights and the full-changelog footer in the post-update welcome notification use the server's language. English highlights remain the fallback when a translation is unavailable.
- **Working full-changelog link.** The welcome notification links to the published changelog rather than an outdated copy.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
- **Add public domains to port-range interfaces.** Services whose interfaces expose a range of ports can add public domains from the web UI or CLI.
