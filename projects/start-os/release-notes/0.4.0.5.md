**0.4.0.5 is a maintenance release fixing command input, environment handling, and service networking.**

## Highlights

- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
- **Subcontainer environment overrides support JSON.** Packages rebuilt with Start SDK 3.1.2 or later keep per-command environment values out of process command lines and preserve multiline image defaults when packed with start-cli 2.5.3 or later.
- **Add public domains to port-range interfaces.** Services whose interfaces expose a range of ports can add public domains from the web UI or CLI.
