**0.4.0.5 is a maintenance release improving data-drive reliability, command input, and service networking.**

## Highlights

- **Automatic data-drive maintenance.** A background Btrfs balance starts after upgrading and runs weekly thereafter to reclaim unused chunks, reducing write failures when the drive still reports free space.
- **Earlier storage warnings.** A notification warns when either data filesystem has little unallocated space left for metadata.
- **Piped commands finish when their input ends.** Commands such as `cat` run through `package attach` receive EOF from piped or redirected stdin and exit normally.
- **Add public domains to port-range interfaces.** Services whose interfaces expose a range of ports can add public domains from the web UI or CLI.
