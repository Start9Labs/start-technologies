**0.4.0.4 is a maintenance release with minor fixes.**

## Highlights

- **Menus and dropdowns open with reduced motion on.** The Start Menu, the Marketplace registry picker, and every other dropdown in the web UI show again when your browser or operating system has reduced motion turned on.
- **Action menus fit their items.** Menus opened near the right edge of the screen, such as the actions on a gateway, Wi-Fi network or backup target, size to fit their items.
