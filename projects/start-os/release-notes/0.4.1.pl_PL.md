## Nowości

- Added opt-in background conversion of existing backups to the authenticated filesystem format, with weighted overall progress, all phases listed upfront, explicit resumption after interruption, and success or failure notifications naming the target. Creating a backup offers to update this server’s older format or skip conversion; restoring marks each old-format server backup with an explanatory warning tag. Unconverted backups remain usable for backups and restores.

- Added named read-only snapshots to the `startos-backup-fs` utility, with explicit creation, listing, deletion, and recovery mounts. Snapshots share unchanged data and retain earlier versions as the current backup changes; retention is managed manually.

- Tokeny Bearer obsługują klientów API, którzy nie mogą podpisywać żądań. `start-cli auth token create --name <name>` wyświetla token tylko raz; żądania z `Authorization: Bearer <token>` uwierzytelniają się jako sesja o podanej nazwie, widoczna i możliwa do unieważnienia na liście sesji. Tokeny nieaktywne przez 30 dni są unieważniane tak jak pozostałe sesje.

- Nowy serwer MCP pod `/mcp`: agenci AI i inni klienci MCP mogą wywoływać API StartOS jako narzędzia przez transport strumieniowego HTTP, uwierzytelniając się tokenem okaziciela z `start-cli auth token create`.

- Nowe `package.exec` w API, dostępne także jako narzędzie MCP: uruchamia polecenie w podkontenerze usługi do końca i zwraca jego wyjście oraz kod wyjścia, z opcjonalnym wejściem standardowym i limitem czasu.

- Zarządzaj nazwanymi zaufanymi zestawami kluczy w responsywnej tabeli System z menu edycji i usuwania w każdym wierszu oraz niezależnym zaufaniem dla pakietów i systemu. Nowe zestawy domyślnie ufają tylko pakietom. Importuj publiczne klucze Ed25519 w formacie PEM lub tekstowym GPG, uwzględniając unieważnienia zapisane w eksportach GPG i zachowując pełne certyfikaty z imionami, nazwiskami i adresami e-mail. Wbudowane zestawy pozostają na początku, mają nazwy tylko do odczytu i nie mają opcji usuwania; oba przełączniki zaufania pozostają dostępne.
- Zmienia nazwę Klucze SSH na Dostęp SSH.
- Pokazuje zaufanych podpisujących pakiety, blokuje niezaufane instalacje Marketplace i wymaga jawnego potwierdzenia przy ręcznym instalowaniu niezaufanego oprogramowania.
- Instalacje pakietów i aktualizacje systemu przez CLI domyślnie wymagają zaufanych podpisujących; `--trust` jawnie pomija ten wymóg, zachowując sprawdzanie podpisu i integralności.

- Włącz powiadomienia push w oknie ustawień strony Powiadomienia, aby otrzymywać powiadomienia StartOS przy zamkniętym interfejsie, również przez udostępniane przez przeglądarkę samodzielnie hostowane punkty końcowe UnifiedPush.

- **Formatowanie dysku na kopie zapasowe w StartOS.** W menu `Ustawienia > Utwórz kopię zapasową` opcja „Sformatuj dysk” wymazuje podłączony dysk i tworzy na nim jedną partycję Btrfs gotową na kopie zapasowe. Dysk zawierający StartOS lub jego dane jest odrzucany. Dostępne również jako `start-cli disk format`.

- Zgodne aktualizacje bezpieczeństwa ogłaszane przez wybrany rejestr systemu pojawiają się w Powiadomieniach i korzystają z powiadomień push przeglądarki, jeśli są włączone. Ich odnośnik aktualizacji oprogramowania otwiera System → Ogólne.
- Aktualizacje beta mogą zastąpić wcześniejszą kompilację o tym samym numerze wersji systemu.

- Przechowuje klucze z typami strukturalnymi bez otoczki PEM, zachowując podczas aktualizacji istniejące logowania i zaufane klucze podpisujące aktualizacje.

- Karta „Zależności” usługi pokazuje zainstalowaną wersję każdej zależności. Zależność w niezgodnej wersji otwiera Sklep na zgodnej wersji.

- Starting and loading health checks can show a clock while waiting for an external condition. All health statuses display nonempty service-provided messages as-is; empty messages use the status label.

- Nieszyfrowane połączenia usług przechodzą przez StartOS przy włączonym proxy HTTP. Aplikacje widzą StartOS jako drugą stronę połączenia TCP; adresy IP klientów są dostępne w `X-Forwarded-For`, gdy włączone jest generowanie nagłówków przekazywania.

- Surowe połączenia TLS usług niewymagających proxy HTTP zachowują źródłowe adresy IP klientów.

- Prevented stale backup data beyond a file's saved length from reappearing when the file grows after an interrupted write.

- Allow retrying an interrupted first backup when no encryption key was saved, reclaiming its unusable encrypted data through the target trash.
- Prevent concurrent first opens from publishing different encryption keys for the same backup store.

- Odzyskuje nieużywane grupy bloków na dysku danych przez pierwsze równoważenie Btrfs w tle po aktualizacji, a następnie cotygodniową konserwację.
- Ostrzega, gdy zaczyna brakować miejsca na alokację metadanych dysku danych, zanim usługi napotkają błędy zapisu mimo zgłaszanego wolnego miejsca.

- Kopie zapasowe i odzyskiwanie z folderów sieciowych obsługują nazwy hostów DNS zawierające kropki. Same nazwy komputerów nadal korzystają wyłącznie z NetBIOS, a błędy wyszukiwania wskazują użyty mechanizm rozwiązywania nazw.

- Przyjmuje nadpisania środowiska podkontenerów przez `JSON_ENV_*`, w tym wartości wielowierszowe i usuwanie zmiennych.
- Zachowuje wielowierszowe wartości domyślne środowiska obrazu w `package attach`.
- Respektuje jawne usunięcie `HOME` bez przywracania wartości domyślnej.

- **Nowości w Twoim języku.** Opis nowości i odsyłacz do pełnej listy zmian są wyświetlane w języku serwera przed aktualizacją i po niej. Jeśli tłumaczenie jest niedostępne, opis nowości jest wyświetlany po angielsku.
- **Poprawny odsyłacz do pełnej listy zmian.** Powiadomienie powitalne odsyła do opublikowanej listy zmian zamiast do jej nieaktualnej kopii.

- Naprawiono odnośniki zależności, przez które Sklep pozostawał na ekranie ładowania.

- Backups to network shares are much faster, especially over high-latency links such as remote sites reached through StartTunnel. Backup data is now written in large batches with many requests in flight, instead of waiting for a network round trip on each small write.

- Aktualizacja ze StartOS 0.3.5 przenosi każdy adres `.onion` z portami, które tam obsługiwał, także dla usług, których migracja kończy się po Torze. Interfejs, który w 0.3.5 nie miał adresu Tor, nie otrzymuje go.

- **Polecenia korzystające z potoku kończą działanie po zakończeniu wejścia.** Polecenia takie jak `cat`, uruchamiane przez `package attach`, otrzymują EOF ze standardowego wejścia przekazanego potokiem lub przez przekierowanie i kończą działanie normalnie.

- Interfejs nie zawiesza się już po aktualizacji StartOS. Okno wymagające odświeżenia pokazuje postęp synchronizacji interfejsu, udostępnia Odśwież po jej zakończeniu i umożliwia odzyskanie działania, jeśli synchronizacja się nie powiedzie lub zatrzyma.

- **Dodawanie domen publicznych do interfejsów z zakresami portów.** W usługach, których interfejsy udostępniają zakres portów, można dodawać domeny publiczne z interfejsu internetowego lub CLI.
- Włączone zakresy portów zachowują przypisanie skonfigurowanych domen podczas sprawdzania duplikatów.

- Usunięcie bramy usuwa również wybory adresów dokonane na niej przez usługi.

- Gateways selected for outbound traffic by the server or a service must be deselected before removal, preventing removal from cutting off outbound connectivity.

- Dodawanie tunelu zgłasza błąd po 30 sekundach, jeśli jego interfejs sieciowy pozostaje niedostępny, zamiast czekać bez końca.

- Interfejs oferuje działania naprawcze, gdy jego kopia w pamięci podręcznej jest uszkodzona.
- Interfejs szybciej wykrywa własną aktualizację po aktualizacji StartOS.

## Bezpieczeństwo

- Strengthened backup encryption authentication and password-protected key wrapping, and removed backup encryption keys from process arguments and recovery errors. Authenticated current references reject substitutions of individual stored records; rollback to a genuine older complete backup view remains possible. Existing backups remain usable for backups and restores until explicit conversion. Conversion rewrites encrypted data, resumes after interruption, and prevents older StartOS releases from reading the converted target.

- Skonfigurowana polityka uwierzytelniania proxy HTTP jest egzekwowana zarówno dla nieszyfrowanych połączeń usług, jak i połączeń TLS.

- Odwiedzane strony internetowe nie mogą już używać Twojej przeglądarki do sterowania serwerem, który jest konfigurowany lub działa w trybie diagnostycznym. Podczas konfiguracji i diagnostyki otwieraj serwer pod jego adresem `.local` lub adresem IP. Dziękujemy dritzps za zgłoszenie.

- Zaktualizowano node-forge do wersji 1.4.2.

- Pakiety systemowe kontenerów usług zawierają dostępne poprawki bezpieczeństwa Debiana, w tym poprawkę dekodera Brotli.

## Important

Existing OS-update trust selections are preserved during migration. If individual Start9 keys were removed, the remaining trusted keys are retained as separate entries rather than enabling the complete Start9 group for OS updates.

Production Marketplace packages must be re-signed with an enabled Start9 key before rollout. Packages signed only by Start9 Alpha or other untrusted keys remain blocked unless their publisher is explicitly enabled.

- Clients of an HTTP-proxied service with configured authentication must provide those credentials on plaintext connections too.

- Services with HTTP proxying enabled now see StartOS as their TCP peer on plaintext connections. Client addresses are available through `X-Forwarded-For` when the binding enables header generation.

- Downgrading to an earlier StartOS version restores that version's HTTP authentication behavior, including its unprotected plaintext connections. Downgrades are blocked for HTTP authentication policies without a TLS wrapper; add TLS to those bindings before downgrading.
