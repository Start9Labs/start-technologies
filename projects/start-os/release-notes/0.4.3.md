## Important

When upgrading from a version before 0.4.2, check your services' public domains and turn back on any you want to use. Some may be switched off if the domain and its public IP addresses had different on/off settings.

BitTorrent downloads are optional and start disabled. When enabled, registry downloads prefer advertised torrents. HTTP downloads already expose an IP address to the server; BitTorrent widens that audience to trackers and other peers, which can also see the requested torrent. Outgoing peers see the IP of the default gateway for StartOS, including the StartTunnel exit IP when it provides that gateway. Incoming connections expose the addresses enabled on the page.

**System → Software sharing** shows that gateway. Downloads, sharing stored software and public-address opt-ins for incoming peers all start off. Enable downloads there to opt in; disabling them returns to HTTP without restarting. Incoming connections reuse native interface addresses, Address Requirements and PCP/UPnP forwarding. Onion registries continue to use HTTP through Tor. Recovery updates stream over HTTP.
