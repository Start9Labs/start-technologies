**0.4.0.3 adds hardware-watchdog recovery and persistent crash diagnostics, updates the NVIDIA driver and keeps service-to-service IPv6 access available.**

## Highlights

- **Servers with a supported watchdog restart after a system hang** that prevents the operating system from refreshing the watchdog timer.
- **Crash diagnostics remain available after later restarts.** `gather-debug-info` includes available kernel crash records, kernel logs, the previous boot's journal, watchdog status and NVMe power-state information. See [FAQ](https://docs.start9.com/start-os/faq.html#my-server-restarted-on-its-own).
- **NVIDIA images include driver 580.178.04**, with Linux 7.2 compatibility.
- **Service-to-service IPv6 access stays available** through the internal bridge address while you change access from other networks.
