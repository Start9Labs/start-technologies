**0.4.0.3 strengthens network privacy and access controls, protects service data during failed updates, and fixes service startup and connectivity problems.**

## Highlights

- **DNS queries follow your chosen outbound gateway.** Service and system DNS use their selected gateways, with separate DNS settings for each gateway and overrides for the OS and individual services.
- **Stronger login and service-access protections.** Login rate limits are isolated by server address, gateway and public or private access. Signed requests must match the access route, and services need permission to read another service's action forms and prefilled values.
- **Failed service updates no longer restore stale data from an earlier update.** Package installation also works reliably while a package is still downloading or uploading.
- **Services start reliably on non-English servers and resume after required tasks.** Services such as those running PostgreSQL can start regardless of the server's language. Services resume automatically when their last blocking task clears, unless explicitly stopped.
- **Fewer interrupted connections and unreachable services.** Large responses arrive complete through service HTTPS addresses. Private domains keep resolving when your network's IPv6 prefix changes, and service-to-service IPv6 access stays available while you change access from other networks.
- **Automatic recovery from system hangs on supported hardware.** Servers with a supported watchdog restart after a system hang, and crash diagnostics remain available after later restarts to help diagnose the cause. See [FAQ](https://docs.start9.com/start-os/faq.html#my-server-restarted-on-its-own).
- **Marketplace and service pages open faster** by loading package icons as they are shown.
