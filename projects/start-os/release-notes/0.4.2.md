## Important

Registry downloads prefer BitTorrent when advertised. HTTP downloads already expose an IP address to the server; BitTorrent widens that audience to trackers and other peers, which can also see the requested torrent. Outgoing peers see the IP of the default gateway for StartOS, including the StartTunnel exit IP when it provides that gateway. Incoming connections expose the addresses enabled on the page.

**System → Software sharing** shows that gateway and offers three cascading controls: BitTorrent downloads (on by default), sharing stored software (off by default), and incoming peer connections (off by default). Turning a control off clears and disables the controls below it. Disable downloads there to use HTTP without restarting. Incoming connections reuse native interface addresses, Address Requirements and PCP/UPnP forwarding. Onion registries continue to use HTTP through Tor. Recovery updates stream over HTTP.
