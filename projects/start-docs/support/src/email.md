# Email

Start9 Support emails you a reminder when a reply goes unread. This page covers it and how to turn it off.

## Unread-Reply Reminders

When a reply from Start9 has gone unread for a while, you are emailed a reminder. **Settings** says how long it waits. The reminder links to the chat; reply there, in Start9 Support.

Chats themselves are not emailed. To keep a copy of one, [export it](chats.md#exporting-a-chat).

## Turning Reminders Off

Reminders are a switch under **Email** in **Settings**: **Unread reply reminders**. Every reminder also carries a link that turns them off without signing in.

Emails about your account — sign-up and password links, a recovered access code — are always sent.
