# Chats

Every request for help is a chat, opened under the topic it is about. This page covers starting one, what you can do in it, and what happens when it closes.

## Starting a Chat

Choose **+** (**New chat**) above your chat list and pick a topic. **General** holds StartOS, StartTunnel, StartWRT, Start9 hardware, DIY hardware (installing StartOS on your own machine) and Upgrading to 0.4.0; **Services** holds every service in the Start9 Registry. Then describe what is going on.

The topic tells Dux which product's or service's documentation to work from, so pick the one the question is about. A question about another service belongs in a new chat under that service.

Keep chats on Start9's products and the technologies around them. The [Terms of Service](https://support.start9.com/terms) say what else is out of bounds.

## In a Chat

- **Attach files** with the paperclip in the message field — logs, screenshots, config files. Each file can be up to 25 MB.
- **Share privately** with the lock in the message field, for something only Start9's staff should see. See [Privacy](privacy.md).
- **Request a human** with the person icon in the message field. See [Dux and Helix](dux-and-helix.md#reaching-a-person).
- **Reply to, react to or copy** a message from the toolbar that appears when you hover over it, or by long-pressing it on a phone.
- **Search** the chat from the search icon in its header.

While Dux works on a reply, the chat says so. You can keep writing in the meantime; Dux answers everything you sent together.

**Chat info**, from the info icon in the header, shows the chat's topic, its status, who is in it, and Dux's notes on the case.

## Your Chats

The chat list shows your ten most recent chats, each with a green dot while open and a red one once closed, and a count of replies you haven't read. The arrow above the list opens **All chats**, every chat you have had, with search.

## Paused and Closed Chats

A chat's status is in **Chat info**:

- **Open** — the chat is active.
- **Paused until** a time — Start9 has set the chat aside until then, usually while waiting on something. You can still write in it.
- **Closed** — Start9 has closed the chat, usually once the problem is solved. If [chat transcripts](email.md) are on, a copy is emailed to you.

To pick a closed chat back up, choose **Reopen chat** at the bottom of it. A chat closed a long time ago continues in a new chat instead, linked to the old one.
