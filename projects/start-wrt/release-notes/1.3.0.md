**StartWRT 1.3.0 lets a trusted device publish DNS names into the router, so a StartOS server's private domains resolve for every device on your network.**

## Highlights

- **DNS record publishing.** Turn on **Allow DNS record publishing** on a device's page, and that device can publish DNS names for itself into the router. A StartOS server does it automatically for its private domains; any RFC 2136 client (`nsupdate -v`) can too. Grant it only to a device you trust. A name is served only to networks whose Security Profile can reach that device, and names under `.lan` stay reserved for the router.
- Updated Angular and DOMPurify protect the web interface against disclosed sanitization vulnerabilities.
- A maintained YAML parser replaces the unmaintained implementation.
