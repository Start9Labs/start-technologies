**StartWRT 1.3.1 restores the update check and fixes Wi-Fi password actions on a sorted table.**

## Highlights

- **The router finds updates again.** Registries running start-registry 1.2.0 or later sign updates in a form earlier versions couldn't read, so the router reported itself up to date. When a check fails, **System > Settings > General** now says **Failed to check for updates**.
- **Wi-Fi password Edit and Delete act on the password you chose.** After sorting the Passwords table, they could change or delete a different password.

## Important

- **Quad9 doesn't resolve with Secure (DoH) on.** Quad9 serves DNS-over-HTTPS only over HTTP/2, which the router's DNS resolver (SmartDNS) doesn't speak. A Security Profile or WAN DNS setting that uses Quad9 (`9.9.9.9`) with **Secure** on can't resolve names. Use Cloudflare (`1.1.1.1`), Google (`8.8.8.8`) or AdGuard (`94.140.14.14`) with **Secure** on, or turn **Secure** off for Quad9.
