## Important

- **Quad9 doesn't resolve with Secure (DoH) on.** Quad9 serves DNS-over-HTTPS only over HTTP/2, which the router's DNS resolver (SmartDNS) doesn't speak. A Security Profile or WAN DNS setting that uses Quad9 (`9.9.9.9`) with **Secure** on can't resolve names. Use Cloudflare (`1.1.1.1`), Google (`8.8.8.8`) or AdGuard (`94.140.14.14`) with **Secure** on, or turn **Secure** off for Quad9.
