- **Editar una contraseña Wi-Fi permite cambiar la contraseña.** Antes solo se podían editar la etiqueta y el perfil de seguridad, por lo que había que borrar y volver a crear la entrada. El cambio puede desconectar brevemente todos los dispositivos Wi-Fi; los que usaban la contraseña anterior deben reconectarse con la nueva. La ayuda ya no confunde la etiqueta con el nombre de red que ven los dispositivos. Al guardar una edición después de que la contraseña se haya cambiado o eliminado en otro lugar, se muestra un error explícito.
