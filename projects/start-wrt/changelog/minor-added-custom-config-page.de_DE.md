- Eine Seite, deren Einstellungen in LuCI oder von Hand so geändert wurden, dass StartWRT sie weder anzeigen noch beibehalten kann, listet diese Änderungen jetzt mit Datei und Zeile und einem Link zu LuCI anstelle ihrer Einstellungen auf. Zuvor zeigte die Seite alle paar Sekunden einen Fehler, zeigte falsche Werte oder konnte die Änderung beim Speichern überschreiben. StartWRT schaltet außerdem IPv6 beim Start nicht mehr ab und legt kein zweites Admin-Profil mehr an, weil es LAN-Einstellungen nicht lesen kann. Eine Änderung, die StartWRT liest, aber nicht verwaltet, etwa eine zweite Adresse im LAN, wird stattdessen oberhalb der Einstellungen der Seite vermerkt. Eine Adresse mit Präfixlänge, eine Liste von Adressen, eine statische Zuweisung mit mehreren MAC-Adressen und eine Firewall-Regel, deren Protokolle als eine Option geschrieben sind, werden jetzt gelesen.
