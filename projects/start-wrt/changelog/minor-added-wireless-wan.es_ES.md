- **La WAN inalámbrica conecta el router a otra red Wi-Fi para acceder a Internet**, como respaldo del puerto WAN o en su lugar. Elija una red tras una búsqueda en la nueva pestaña WAN inalámbrica de `Internet > Configuración de WAN`. Los perfiles, los puertos publicados y el acceso remoto la usan igual que el puerto WAN. La página Wi-Fi ya no apaga una banda que lleva el enlace, aunque se haya configurado en LuCI.
