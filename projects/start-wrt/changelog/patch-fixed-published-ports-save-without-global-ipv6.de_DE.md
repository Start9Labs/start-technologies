- **Veröffentlichte Ports lassen sich auch ohne globale IPv6-Adresse des Routers speichern.** Bisher blockierte der Verlust dieser WAN-Adresse jede Änderung, selbst an reinen IPv4-Freigaben, sobald eine IPv6-Weiterleitung bestand. Bestehende IPv6-Weiterleitungen bleiben erhalten und zeigen die fehlende Adresse an; nur neue IPv6-Weiterleitungen benötigen weiterhin eine globale IPv6-Adresse.
