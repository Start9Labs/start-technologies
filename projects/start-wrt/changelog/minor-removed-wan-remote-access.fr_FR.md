- **Le paramètre Accès à distance a été supprimé.** L’interface web et SSH n’acceptent les connexions que depuis votre réseau local et (lorsque c’est explicitement autorisé) vos VPN. Pour gérer le routeur hors de chez vous, connectez-vous via un VPN entrant, ou via un VPN sortant dont l’accès au routeur est activé.
