- **La modification d’un mot de passe Wi-Fi permet de changer le mot de passe lui-même.** Seuls le libellé et le profil de sécurité étaient modifiables ; il fallait supprimer puis recréer l’entrée. Le changement peut déconnecter brièvement tous les appareils Wi-Fi ; ceux utilisant l’ancien mot de passe doivent se reconnecter avec le nouveau. L’aide ne présente plus le libellé comme le nom du réseau visible par les appareils.
