- **Les adaptateurs Ethernet USB ajoutent des ports LAN.** Un adaptateur branché sur l’un des ports USB-A du routeur fait apparaître ce port USB sur la page Ethernet la première fois qu’un appareil réseau y est branché. Attribuez-lui un profil de sécurité comme à tout port Ethernet. Un nouveau port USB commence dans le profil Admin et conserve son profil quand rien n’y est branché. Chaque port d’un hub USB est un port USB à part entière. Un port USB sans adaptateur branché peut être supprimé de la page.
