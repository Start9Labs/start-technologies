- **Wireless WAN connects the router to another Wi-Fi network for Internet access**, as a backup to the WAN port or in its place. Pick a network from a scan on the new `Internet > Wireless WAN` page. Profiles, published ports and remote access use it just as they use the WAN port. The Wi-Fi page no longer turns off a band that carries the uplink, including one set up in LuCI.
