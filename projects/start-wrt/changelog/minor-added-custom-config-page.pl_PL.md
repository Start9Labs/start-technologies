- Strona, której ustawienia zmieniono w LuCI lub ręcznie w sposób, którego StartWRT nie może wyświetlić ani zachować, wyświetla te zmiany, z plikiem i wierszem oraz odnośnikiem do LuCI, zamiast pokazywać błędy lub błędne wartości albo nadpisywać zmianę przy zapisie. StartWRT nie wyłącza już też IPv6 przy starcie ani nie dodaje drugiego profilu Admin z powodu ustawień LAN, których nie może odczytać.
