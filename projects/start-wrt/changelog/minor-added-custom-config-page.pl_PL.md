- Strona, której ustawienia zmieniono w LuCI lub ręcznie w sposób, którego StartWRT nie może wyświetlić ani zachować, wyświetla teraz te zmiany, z plikiem i wierszem oraz odnośnikiem do LuCI, zamiast swoich ustawień. Wcześniej strona co kilka sekund pokazywała błąd, pokazywała błędne wartości lub mogła nadpisać zmianę przy zapisie. StartWRT nie wyłącza już też IPv6 przy starcie ani nie dodaje drugiego profilu Admin z powodu ustawień LAN, których nie może odczytać. Zmiana, którą StartWRT odczytuje, ale którą nie zarządza, na przykład drugi adres w sieci LAN, jest zamiast tego sygnalizowana nad ustawieniami strony. Adres zapisany z długością prefiksu, lista adresów, statyczna dzierżawa z kilkoma adresami MAC oraz reguła zapory, której protokoły zapisano jako jedną opcję, są teraz odczytywane.
