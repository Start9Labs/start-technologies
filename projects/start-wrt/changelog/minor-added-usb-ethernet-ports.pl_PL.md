- **Adaptery USB–Ethernet dodają porty LAN.** Adapter w jednym z portów USB-A routera umieszcza ten port USB na stronie Ethernet, gdy po raz pierwszy zostanie do niego podłączone urządzenie sieciowe. Przypisz mu profil bezpieczeństwa jak każdemu portowi Ethernet. Nowy port USB zaczyna w profilu Admin i zachowuje swój profil, gdy nic nie jest podłączone. Każdy port koncentratora USB jest osobnym portem USB. Port USB bez podłączonego adaptera można usunąć ze strony.
