- **Los adaptadores Ethernet USB añaden puertos LAN.** Un adaptador en uno de los puertos USB-A del router hace aparecer ese puerto USB en la página Ethernet la primera vez que se conecta a él un dispositivo de red. Asígnele un perfil de seguridad como a cualquier puerto Ethernet. Un puerto USB nuevo empieza en el perfil Admin y conserva su perfil aunque no haya nada conectado. Cada puerto de un hub USB es un puerto USB propio. Un puerto USB sin adaptador conectado se puede quitar de la página.
