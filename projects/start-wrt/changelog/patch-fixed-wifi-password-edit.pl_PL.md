- **Edycja hasła Wi-Fi pozwala zmienić samo hasło.** Wcześniej można było edytować tylko etykietę i profil bezpieczeństwa, więc zmiana hasła wymagała usunięcia i ponownego utworzenia wpisu. Zmiana może na krótko rozłączyć wszystkie urządzenia Wi-Fi; urządzenia używające starego hasła muszą połączyć się ponownie z nowym. Pomoc nie myli już etykiety z nazwą sieci widoczną dla urządzeń.
