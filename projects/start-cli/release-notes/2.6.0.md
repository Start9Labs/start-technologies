Start CLI 2.6.0 adds an explicit signer-trust override for installing service packages and updating StartOS.

## Highlights

- Use `--trust` with `package install`, including `--sideload`, or with `server update` and `diagnostic update` to accept software signed by an otherwise untrusted key.
- On StartOS 0.4.1 and later, installation and updates enforce the server's trust policy by default. The override does not skip signature or integrity verification.
