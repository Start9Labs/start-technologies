**start-cli 2.5.2 preserves image-provided resolver symlinks when packing and supports independent WireGuard config endpoints.**

## Highlights

- Packing retains `/etc/resolv.conf` symlinks and their hardlink aliases instead of replacing the resolver with an empty file.
- `tunnel device show-config --endpoint` supplies an IPv4 address, IPv6 address, or DNS name without changing the WAN assignment used for forwarding and SNAT. Requires StartTunnel 1.4.2 or later.

## Important

Packages whose images have a symlinked `/etc/resolv.conf` need SDK 3.1.1 or later before repacking. The SDK installs the runtime resolver when each subcontainer starts.
