**start-cli 2.5.1 fixes macOS startup, closed-pipe crashes, and packing images with a symlinked resolver, and adds independently chosen WireGuard endpoints.**

## Highlights

- Fixed services packed from an image whose `/etc/resolv.conf` is a symlink, such as a Nix-built image, failing to start on StartOS. Repack affected services with this version.
- Fixed macOS binaries aborting before running any command, including `--version`.
- Piping output into a command that stops reading early, such as `head`, no longer crashes the CLI.
- `tunnel device show-config --endpoint` supplies an IPv4 address, IPv6 address, or DNS name without changing the WAN assignment used for forwarding and SNAT. Requires StartTunnel 1.4.1 or later.
