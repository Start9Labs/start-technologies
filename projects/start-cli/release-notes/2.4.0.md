**start-cli 2.4.0 adds local OCI image sources and built-in SquashFS support.**

## Highlights

- **Pack services and add container images with built-in SquashFS support.** `s9pk pack` and `s9pk edit add-image` create compressed images directly. Packaged JavaScript files are readable and their directories traversable by the service runtime, while your source permissions stay unchanged.
- **Use local OCI image layouts or archives.** Images can be selected by platform and reference without a container daemon. Docker Buildx exports OCI directly; custom builds need an OCI-capable builder.
- **Convert legacy packages without Docker or binfmt registration.** Saved image layers are imported directly.
- **Package manifest paths containing apostrophes work during packing and validation.**
