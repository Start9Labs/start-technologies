**start-cli 2.2.0 makes emulated service images portable across CPU architectures.**

## Highlights

- **`s9pk edit add-image --emulate-missing` marks an image as available through CPU emulation** when a server uses another architecture. StartOS selects the image the s9pk contains, including one retained in a backup. The previous `--emulate-missing-as <ARCH>` spelling remains accepted for existing scripts.
