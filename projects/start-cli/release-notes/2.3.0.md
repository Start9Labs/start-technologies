**start-cli 2.3.0 packs multi-architecture images for any target architecture again, and adds registry administration options for start-registry 1.1.1.**

## Highlights

- **`s9pk pack` and `s9pk edit add-image` preserve the requested platform's image configuration**, so a multi-architecture image packs for an architecture other than the host's, such as riscv64 on an x86 machine or CI runner. Packing with Docker now requires Docker 28.1 or later.
- **`registry package get <ID> full --all-revisions` lists every revision of a package a registry holds**, including the ones a registry hides once a newer revision of the same upstream version runs on the same hardware.
- **`registry info set-icon --clear` and `registry info set-description --clear` remove a registry's icon and description.**
