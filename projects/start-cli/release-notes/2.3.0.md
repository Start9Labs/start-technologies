**start-cli 2.3.0 adds registry administration options for start-registry 1.1.1.**

## Highlights

- **`registry package get --all-revisions` lists every revision a registry holds**, including the ones a registry hides once a newer revision of the same upstream version runs on the same hardware.
- **`registry info set-icon --clear` and `registry info set-description --clear` remove a registry's icon and description.**
