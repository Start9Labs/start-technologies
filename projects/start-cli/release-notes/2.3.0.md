**start-cli 2.3.0 lets a running backup finish before restarting or shutting down your server.**

## Highlights

- **`server restart` and `server shutdown` defer the power action by default** until any running backup finishes. Use `--force` to interrupt the backup instead. Cancel a pending action with `server cancel-deferred-power`. Requires StartOS 0.4.0.3 or later.
