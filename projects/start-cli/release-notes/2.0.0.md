**start-cli 2.0.0 renames one command and changes two signatures** — a provisioning or unattended-install script that names a server needs updating. See Important below.

## Highlights

- **`s9pk pack` packs the package's `README.md`**, beside `instructions.md` in the archive. An assistant administering a service can read that package's technical reference out of the installed `.s9pk` — offline, and describing the version actually installed. It is optional, so a package without one still builds.
- **`server epp` shows or sets the CPU's energy/performance preference**, persisted across reboots, and reports the values the server supports.
- **`registry os asset remove` can be run.** Its `iso`/`img`/`squashfs` subcommands now take `<VERSION> <PLATFORM>`, so one platform's asset can be dropped without removing the whole version and re-adding every other platform.
- **The local authcookie reaches a daemon that listens on a wildcard address.** `start-cli registry admin list` on the registry host used to come back `Unauthorized`, because a derived `0.0.0.0:5959` address is not literally loopback. An explicit `--registry` / `--tunnel` target is unchanged: the token still goes only to a loopback URL.
- **`s9pk init-workspace` clones the monorepo's `live-docs` branch**, so a workspace's packaging guide, package template and SDK source describe the `@start9labs/start-sdk` its packages install. Move an existing workspace over with `git -C start-technologies checkout live-docs`.
- **A fresh workspace works out of the box** — `init-workspace` no longer scaffolds the `dev-vm.local` host, which resolved nowhere and failed every command. Comment it out in an existing workspace.
- **An `s9pk` command tells you when `start-cli` is behind the published release.** It installs outside the workspace, so nothing else would have.

## Important

**`server governor` replaces `server experimental governor`.** Scripts that set or inspect the CPU governor need the direct `server` subcommand.

**`server set-hostname` takes one required hostname, and `setup execute` no longer takes `--name`.** A StartOS server now carries a single name — its `.local` hostname — where it used to carry a separate display label as well, so setting it moves the address the server answers to. Both commands also reject a name longer than 32 characters, or one starting or ending with a hyphen, which 1.1.0 accepted.
