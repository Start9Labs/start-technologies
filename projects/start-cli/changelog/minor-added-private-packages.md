- **`registry package access` manages private packages on start-registry 1.3.0**: `set-private`,
  `add-reader`, `remove-reader`, and `get`.
- **`server registry-signing` chooses which registries a StartOS server signs its requests to**:
  `add`, `remove`, and `list` take registry URLs, and `key` shows the key the server signs with.
