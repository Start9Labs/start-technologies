Use a local forwarding address and a separate WireGuard endpoint on hosts behind NAT.

## Highlights

- `device show-config --endpoint-ip` supplies the IPv4 or IPv6 endpoint in a generated config without changing the WAN assignment used for forwarding and SNAT.
- The existing subnet and device `set-wan` commands accept the host's private local IPv4. The CLI documentation explains the manual forwarding workflow and upstream NAT requirements.

## Important

With a non-public WAN override, generating a WireGuard config requires `--endpoint-ip`. Supply the address the device uses to reach the tunnel host each time. Configs already installed on devices remain unchanged.
