**StartTunnel 1.3.1 clears stale port forwards when the daemon starts and keeps open browser pages current across future updates.**

## Highlights

- **Port forwards left behind by an earlier run of the daemon are cleared at startup**, so a crash or a WAN address change can no longer leave a port sending traffic to an old address until the next reboot.
- **Open pages can load the current web interface after future updates.** Pages opened on this release revalidate the interface when they reload. Perform one hard refresh after installing this release to replace an interface cached by an earlier version.
