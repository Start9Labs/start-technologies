## Wichtig

Wählen Sie einen Endpunkt, der vom Gerät erreichbar ist; ein HTTPS-Reverse-Proxy leitet WireGuard-UDP möglicherweise nicht weiter. Der konfigurierte WireGuard-Port bleibt erhalten. Die Konfigurationserzeugung per CLI mit einer nicht öffentlichen WAN-Zuweisung erfordert `--endpoint`. Bereits auf Geräten installierte Konfigurationen bleiben unverändert.
