- **Les configurations WireGuard peuvent utiliser un point de terminaison distinct lorsque StartTunnel est derrière un NAT.** Le dialogue reprend par défaut l’hôte de l’URL du navigateur et accepte une adresse IP ou un nom DNS modifiés. `device show-config --endpoint` offre le même réglage par configuration, indépendamment de l’adresse WAN utilisée pour le SNAT et les redirections.
