**start-registry 1.2.1 lets StartOS 0.4.0.3 servers update to OS releases signed with gpg-held keys.**

## Highlights

- **StartOS 0.4.0.3 receives pure Ed25519 signatures.** 1.2.0 withheld them from 0.4.0.3, which supports them, so those servers saw such an update as unsigned and the UI refused to install it.
