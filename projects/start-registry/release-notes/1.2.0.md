**start-registry 1.2.0 adds private packages, visible only to the signers an admin allows.**

## Highlights

- **`package access set-private <ID> true` makes a package private.** It disappears from `package get`, `package index`, `index`, and `package signer list` for everyone except admins, its authorized signers, and its readers, which `package access add-reader <ID> <SIGNER>` adds. A reader's requests must be signed: start-cli signs with its developer key, and StartOS signs to the registries added with `start-cli server registry-signing add <URL>`.
