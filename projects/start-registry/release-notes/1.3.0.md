**start-registry 1.3.0 serves StartWRT as a product of its own, and keeps older StartOS servers and StartWRT routers able to update when a new release is signed with gpg-held keys.**

## Highlights

- **A registry names the product it serves.** Set `product: startwrt` in a StartWRT registry's config; `startwrt: true` still works. A current StartOS server or StartWRT router pointed at the other product's registry receives an error naming the product the registry serves.
- **Clients declare the signature formats they read.** Current StartOS, StartWRT, and start-cli receive current signature labels from any registry, without the registry guessing from a version number.
- **Older devices are offered only releases they can verify.** A StartOS server older than 0.4.0.3, or a StartWRT router older than 1.3.1, updates to the newest release it can install, then onward from there.
