**start-registry 1.1.1 keeps every package revision in the index while showing clients only the ones they need, and brings shared dependencies up to date with their security fixes.**

## Highlights

- **`package get` hides a revision once a newer revision of the same upstream version runs on all the same hardware.** A registry can keep every revision indexed, with its publish date, instead of removing old ones to keep the marketplace's version list tidy. `package get <id> full --all-revisions` lists every revision the registry holds.
- **`info clear-icon` and `info clear-description` remove a registry's icon and description.**
- **Shared dependencies are updated with their security fixes**, and the unmaintained YAML parser is replaced.
- **A registry accepts admin requests at any loopback address**, such as `start-cli -r http://127.0.0.1:5959` on the registry's own host.
- **Each release's container image is published as `ghcr.io/start9labs/startos-registry:v<version>`.**
