Daemon and subcontainer environments travel outside process command lines, and image defaults support multiline values.

## Highlights

- Keep per-command environment values, including secrets, out of process listings. Rebuild packages with this SDK to receive the fix.
- Preserve multiline image environment values when packing with start-cli 2.5.3 or later. Existing packages' image environment files remain supported.
- Preserve caller-owned command options when reusing `spawn` or `launch` options.

## Important

Packages built with this SDK require StartOS 0.4.0.5 or later.
