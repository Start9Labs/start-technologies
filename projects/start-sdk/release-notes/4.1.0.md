## Important

- When upgrading a package that uses `Value.file` or `Value.dynamicFile`, prepare its destination during form construction with `sdk.prepareUpload` and pass the returned `uploadId` to the field. Custom clients upload the bytes first, then submit that ID as the field value. See [File Upload](https://docs.start9.com/packaging/actions.html#file-upload).
- Install StartOS 0.4.2 or later before installing packages built with SDK 4.1.0.
