**A patch release: package authors gain more precise types and inferred RPC methods, parameters and results.**

## Highlights

- **Types distinguish accepted inputs from serialized outputs.** Input types include serde defaults and legacy-compatible request forms; output types describe normalized responses. RPC methods, parameters and results are inferred from the server handlers, and Rust documentation is available in editor hovers.
- **Effects return types match their wire results.** Container addresses can be null, certificates are string arrays, and mounts return null.
