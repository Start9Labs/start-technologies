## Important

- When upgrading a package to SDK 5.0.0, update `buildManifest` in `startos/index.ts` to take named arguments and the package's `i18n`: add `import { i18n } from './i18n'`, then call `buildManifest({ versionGraph, manifest: sdkManifest, dependencies, i18n })`. The package template already does this.
- `Value.text`, `Value.textarea`, `Value.color` and `Value.datetime` reject `''`, including their dynamic variants and static file-model validators. Direct action callers must send `null` for an empty optional field. `List.text` and `List.dynamicText` require non-empty string items. Packages reusing these validators for file models must migrate stored empty strings before reading them with SDK 5.0.0: use `null` for optional fields, valid non-empty values for required fields, and replace or remove empty list items. For upstream files where `''` is valid, use a separate Zod schema that accepts it.
