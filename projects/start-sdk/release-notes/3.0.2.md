**A one-fix patch release: a package's migrations run after a flavor switch.**

## Highlights

- **Migrations run after a flavor switch.** Switching a service between flavors records the exact version installed as its data version, so later `up()` migrations in that series run.

## Important

- **A range already recorded is replaced, not replayed.** An install whose data version is a range, from a switch made under an earlier SDK, settles on the current version at its next initialization. The migrations it skipped do not run, so do work an install like that still needs outside a migration.
