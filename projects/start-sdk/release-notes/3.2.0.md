Service packages can opt into Gitea Actions for builds, releases, registry publishing, and automatic `next` branch synchronization. Subcontainers start from images with no `/proc` and replace the image's resolver with the runtime resolver, including when the image provides a symlink.

## Highlights

- **Opt-in Gitea CI**, with self-contained workflows supplied by the packaging guide. The supported baseline is Gitea 28.1.0 with Gitea Runner 5.1.1. Refresh the package's copies to pick up shared workflow updates.
- **Registry-query errors receive their intended handling.** Release publishing warns and continues after a failed lookup, while reference-registry checks report an error before stopping.
- Fixed subcontainer startup with a symlinked `/etc/resolv.conf` and preserved other files linked to an image's resolver. Rebuild packages with this SDK version to receive the fix.
- Fixed subcontainer startup from an image with no `/proc`, such as one built `FROM scratch`. Rebuild packages with this SDK version to receive the fix.
