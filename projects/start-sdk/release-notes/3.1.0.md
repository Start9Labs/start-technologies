Service packages can run their CI on self-hosted Forgejo, validate any StartOS type at runtime, and run a health check exactly once.

## Highlights

- The package template includes `.forgejo/workflows/` with explicit action URLs, Forgejo-compatible artifacts and releases, registry publishing, and automatic `next` branch synchronization. Existing GitHub workflows remain available under `.github/workflows/`.
- **`schemas` exports zod validators for every OS type.** `schemas.Manifest.parse(...)` and friends validate values against the same shapes as the `T` types.
- **`sdk.trigger.onceTrigger` runs a health check once, when it starts.** Pair it with `gracePeriod: 0`, which now reports the first result as returned, for a check whose result cannot change until `main` restarts.
- **Manifests accept local OCI images** through `source.ociLayout`, from a layout directory or a tar archive. Packing one needs start-cli 2.4.0 or later.
- **Forward Email is a provider preset in the SMTP input spec**, and the presets are listed alphabetically.
- **`make` formats `startos/` instead of rejecting unformatted source**, so a package build no longer fails on formatting. A `Makefile` that overrode `FORMAT_CHECK` overrides `FORMAT` instead.
