# Contributing

This repository contains the Start9 products. For service packaging, see the
[packaging guide](https://docs.start9.com/packaging). For other ways to contribute,
visit [Start9](https://start9.com/contribute).

Read [AGENTS.md](AGENTS.md) for the shared toolchain, development workflow,
branch policy, and commit and pull request conventions. Each product adds its
specific workflow in its own `AGENTS.md`.

Discuss development in [Matrix](https://matrix.to/#/#dev-startos:matrix.start9labs.com).
Report security issues through [SECURITY.md](SECURITY.md).
